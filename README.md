# 디지털 포렌식 전문가 2급 필기

모바일 중심 기출 풀이. 맞춘 문제·틀린 문제는 브라우저 localStorage에만 저장됨.

## 주소

https://lignah.github.io/df2/

## 로컬 실행

```bash
npm install
npm run dev
```

기본 포트는 3000.

```bash
npm run build
npm run preview
```

## 과목

- 컴퓨터구조와 디지털저장매체
- 파일시스템과 운영체제
- 응용프로그램과 네트워크
- 데이터베이스
- 디지털포렌식 개론(기초실무·법률)
